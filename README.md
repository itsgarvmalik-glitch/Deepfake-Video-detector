# Deepfake-Video-detector
Deepfake video detection system using a Spatial-Temporal Attention model: ResNeXt-50 extracts per-frame features, CBAM highlights manipulated facial regions, and a BiLSTM captures temporal inconsistencies across frames. Supports FaceForensics++, Celeb-DF and DFDC, with a FastAPI backend, React web UI, and attention heatmap visualization.
